# Web 控制台详解

项目是一个单页 Web 控制台：扫码登录、浏览/下载每日推荐、按歌单或专辑下载、设置定时自动下载。
**所有设置都在网页上完成，没有配置文件**（旧版的 `config.yaml` 和 cron 批处理已移除）。

**启用**：只需映射两个目录——下载目录 + 一个数据目录，不再需要 `config.yaml`：

```yaml
    volumes:
      - ./downloads:/app/downloads  # 下载目录
      - ./data:/app/data            # 数据目录：登录凭证、页面设置、定时任务、日志（logs/）
    ports:
      - "5119:5119"
    environment:
      - WEB_PORT=5119
      - HOST_DOWNLOAD_DIR=/volume1/share/music/netease   # 可选：上面 ./downloads 在宿主机上的真实路径，仅用于页面显示「将保存到」
      - WEB_PASSWORD=change-me      # 强烈建议设置：页面可操作登录凭证与下载；用户名默认 admin（WEB_USER 可改）
```

访问 `http://主机:5119`。Bark、音质、请求间隔、音乐库（Navidrome / music-tag-web）等设置都在页面上配置，保存即生效。

**从旧版升级**：程序不再读取 `config.yaml`（Bark、音质、间隔、音乐库都只认页面设置）。若你以前靠 `config.yaml` 提供这些值、
且从没在页面保存过，请升级后到「设置」页重新填一遍。`CRON_ENABLE`、`CRON_SCHEDULE`、`RUN_ON_START`、`WEB_ENABLE` 等环境变量已无作用，可从 compose 删除。
日志写在 `./data/logs/`；仍单独映射了 `./logs:/app/logs` 的老用户不受影响。

**页面结构**：五个 Tab——「下载」「自动下载」「任务记录」「推荐」「设置」（推荐联动的任务日志在「任务记录」里，推荐联动的配置在「设置」页底部，默认折叠），当前 Tab 记在 URL 的 `#` 后（刷新不丢）；未登录时只显示扫码。

**功能**

- **扫码登录**：用网易云 App 扫码，cookie 保存在 `data/web_state.json`（权限 600），无需手抄 cookie。
- **下载来源**：每日推荐（默认）、今日日期歌单、我的歌单（日期命名的排在最前，如 `20260108`）、
  任意歌单/专辑（粘贴 ID 或分享链接）。可先预览，再「下载全部」或勾选部分歌曲下载。
- **下载目录**：默认下载根目录（映射进来的 `/app/downloads`），也可选已有子目录或新建子目录（最多 3 层，禁止越界）。
- **借用黑胶 VIP 账号下载**：登录账号 A 不是黑胶 VIP 时，可在「设置 → 下载账号」添加一个黑胶 VIP 账号 B 的登录凭证，
  下载时改用 B 的权限取下载链接、详情和歌词（**歌单、每日推荐仍用 A 获取**），因此 A 也能下无损。
  - 添加方式：**扫码**（让 B 本人用 App 扫），或**粘贴导入** B 的 `web_state.json` 里的 `account` 节点（整个文件、account 节点、纯 cookie 都可以）。
  - **必须是黑胶 VIP**：导入时会用 cookie 向网易云重新校验（不信任粘贴内容自带的昵称/VIP 字段），非 VIP 拒绝。
  - **A 已是黑胶 VIP 时不需要借用账号**：页面会隐藏相关控件并说明，任务也直接用 A 自己的凭证，不会去校验、不会动借用账号。
  - **借用账号失效（登录过期/已不是 VIP/被删）时任务直接失败**，并推送 Bark 通知，不会静默退回 A（否则 A 非 VIP 时会悄悄变成只下 MP3）。
  - 凭证只存在 `data/web_state.json`（权限 600）的 `download_account` 节点，接口与页面永远不回显。**请把 `WEB_PASSWORD` 设成强密码。**
    注意：同一账号同时在 B 自己的设备和你的 NAS 上使用，网易云可能要求 B 重新登录，借用账号会不时失效，属正常。
- **账号类型**：黑胶 VIP 按音质设置下载（默认 lossless）；**非 VIP 只下载 MP3（极高 320k）**，
  VIP 专享、仅能试听的歌曲会被跳过。
- **自动下载（定时）**：每个任务 = 来源 + 子目录 + 每天一个或多个 `HH:MM`，可启用/停用/立即运行；
  按容器 `TZ` 触发，停机期间错过的时间点不补跑；同一任务上一次未结束时不会重叠运行。
- **页面可调的设置**（保存在 `data/web_state.json`，权限 600）：
  - **Bark 推送地址**（可留空关闭，可点「测试」）；
  - **音乐库去重**：选 Navidrome 或 music-tag-web(MySQL) 并填写连接信息，可「测试连接」；只有一个控件——类型选「不使用」即关闭（已填的连接信息会保留）；
    密码保存后不再回显（留空 = 不修改）；
  - **音质**（仅 VIP）、**请求间隔**（每首歌之间的秒数）。
- **任务记录（逐首可查）**：每次运行（手动/定时）都记录每一首歌的结果——成功 / 失败 / 跳过 / 库中已有 / 本地已有。
  点开任务可按状态筛选，失败项显示**分类原因 + 接口原始返回**（如 `code=404 fee=0`），并带「去网易云查看」链接直达该歌曲页。
  失败分类：无版权/已下架、VIP 专享、需单独购买、无下载链接、接口错误、下载失败、其它。
  最多保留最近 **1000** 个已结束任务；逐首明细单独存在 `data/job_details/<任务id>.json`（任务被清理时同步删除）。升级前产生的旧任务没有逐首明细，只显示汇总与日志。
- 多个任务（手动 + 定时）会**排队依次执行**，避免对网易云造成突发请求而触发风控。

**说明**：Web 控制台下载时**接受 MP3**（因为非 VIP 账号只能拿到 MP3）；推荐联动则只要无损。
