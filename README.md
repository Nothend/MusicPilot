# 佛系云音乐自动下载

[![Docker Hub](https://img.shields.io/docker/pulls/leonautilus/auto-music-downloader?logo=docker)](https://hub.docker.com/r/leonautilus/auto-music-downloader)

把网易云音乐里你喜欢的歌，**自动下载成带歌词、封面、歌手信息的无损音乐文件**，放进你自己的音乐库（NAS、Navidrome、Plex 等）。
不用每天手动点下载，也不会重复下载已经有的歌。

> ⚠️ 需要一个**网易云黑胶会员（VIP）**账号才能下载无损音质；没有会员只能下载 MP3（320k）。

---

## 它能帮你做什么

| 场景 | 怎么用 | 说明 |
|---|---|---|
| **每天的「每日推荐」** | 把喜欢的歌加进一个以当天日期命名的歌单（如 `20261121`） | 程序定时扫描这个歌单，只下载你库里还没有的新歌 |
| **下载某个歌单 / 专辑** | 在网页里粘贴歌单或专辑链接 | 先预览，再全部下载或勾选部分 |
| **听「别人」推荐的新歌** *(可选)* | 接入 [ListenBrainz](https://listenbrainz.org) 与 Navidrome | 自动把它给你生成的推荐歌曲下载到「试听库」，你喜欢的点个红心，就自动移进正式音乐库，不喜欢的 7 天后自动清理 |

主要特点：

- 🎵 **网页操作**：手机扫码登录网易云，不用自己抄 Cookie；下载、定时任务、任务记录都在网页里完成。
- 🏷️ **标签齐全**：自动写入歌名、歌手、专辑、年份、歌词（含翻译）、封面。
- 🔁 **不重复下载**：能和 Navidrome / music-tag-web 比对，库里已有的直接跳过。
- 🛡️ **安全**：文件先写临时文件、校验完整才改名，不会留下半截文件；推荐联动只往正式音乐库里**新增**文件，绝不覆盖、不删除。
- 📱 **手机友好**：页面适配手机，下载完成可用 [Bark](https://github.com/Finb/Bark) 推送到手机（可选）。

> 它**不是**批量下载工具：设计目标是「日常增量更新」（每天 30 首左右），请合理使用。

## 3 分钟上手（Docker）

你需要一台能跑 Docker 的机器（群晖 / 绿联 / 威联通 NAS、Linux 服务器、软路由都行）。

**1. 新建一个文件夹，放入 `docker-compose.yml`：**

```yaml
services:
  auto-music-downloader:
    image: leonautilus/auto-music-downloader:latest
    container_name: auto-music-downloader
    restart: always
    ports:
      - "5119:5119"                 # 网页端口
    volumes:
      - ./downloads:/app/downloads  # 歌曲下载到这里（可改成你的音乐目录）
      - ./data:/app/data            # 登录信息、设置、记录（请定期备份）
    environment:
      - TZ=Asia/Shanghai            # 时区，务必设对
      - WEB_ENABLE=true
      - WEB_PORT=5119
      - WEB_PASSWORD=请改成你自己的密码   # 网页登录密码，用户名是 admin
      - CRON_ENABLE=false           # 只用网页，不需要旧的定时脚本
```

**2. 启动：**

```bash
docker compose up -d
```

**3. 打开 `http://你的机器IP:5119`**，输入用户名 `admin` 和刚才设的密码，用网易云 App 扫码登录，就可以在「下载」页下载每日推荐或歌单了。

**4. 想每天自动下载？** 到「自动下载」页添加一个定时任务（例如「每日推荐」每天 21:00）。

> 💡 **强烈建议设置 `WEB_PASSWORD`**：网页里能操作你的网易云登录凭证。不要把 5119 端口直接暴露到公网。

## 页面一览

| 标签页 | 用来做什么 |
|---|---|
| **下载** | 选来源（每日推荐 / 今日日期歌单 / 我的歌单 / 任意歌单或专辑链接）→ 预览 → 下载 |
| **自动下载** | 设置每天几点自动下载什么，可随时启用 / 停用 / 立即运行 |
| **任务记录** | 每次下载的结果，逐首可查；失败会写明原因（无版权、VIP 专享、需购买……） |
| **推荐** | ListenBrainz 推荐联动的概览与歌单（不用这个功能可忽略） |
| **设置** | 通知、音质、下载账号、音乐库去重；页面底部有可折叠的「推荐联动设置」 |

---

## 常用设置

- **音质**：默认无损（`lossless`）。可选标准 / 极高 / 无损 / Hi-Res / 沉浸环绕声 / 超清母带（需 VIP）。
- **不是会员但朋友是？** 可在「设置 → 下载账号」添加一个黑胶会员账号的登录凭证，下载时借用它的权限（歌单仍用你自己的账号获取）。
- **接入音乐库去重**：在「设置 → 音乐库去重」选择 Navidrome 或 music-tag-web 并填写地址，库里已有的歌会被自动跳过。
- **手机通知**：在「设置 → 通知」填写 Bark 地址，每轮下载完推送结果。

## 进阶：ListenBrainz 推荐联动（可选）

如果你用 **Navidrome** 听歌并开启了 **ListenBrainz** 记录，ListenBrainz 会根据你的口味每天、每周生成推荐歌单。开启本功能后：

```
ListenBrainz 推荐 → 你库里有的直接复用 → 没有的从网易云下载（无损）到「试听库」
   → 在 Navidrome 里试听，喜欢的点红心 → 自动移入正式音乐库
   → 没点红心的，7 天后自动清理
```

- **默认全部关闭**，需要你在「设置 → 推荐联动设置」里一步步配置并明确打开总开关。
- 对库里已有的歌，会自动识别繁简体、异体字、歌手别名、`Radio Edit` 这类剪辑版本，**避免重复下载**。
- 红心还可以同步回 ListenBrainz（可选，默认关闭，先预览再提交）。

完整说明与配置步骤见 **[推荐联动详解](docs/recommendation.md)**。

## 更新与回滚

```bash
docker compose pull        # 拉取最新镜像
docker compose up -d       # 用新镜像重建容器
```

想固定或回滚到某个版本，把 `image` 末尾的 `:latest` 换成具体版本号，例如 `leonautilus/auto-music-downloader:1.1.2`。
升级前建议先备份 `data` 目录。

## 常见问题

**提示「非 VIP」或下载的都是 MP3？**
账号不是黑胶会员，或登录已过期。重新扫码登录；非会员可借用会员账号（见上）。

**找不到今日歌单？**
歌单名必须**正好等于当天日期**（如 `20261121`，不要有空格），并且容器的 `TZ` 要和你所在的时区一致。

**某首歌没被下载？**
可能库里已经有了、网易云只有 MP3 版本，或没有版权。到「任务记录」点开那次任务，会写明每一首的原因。

**担心被网易云限流？**
在「设置」里调大「请求间隔」。程序遇到限流会自动退避重试，不会硬冲。

**推荐歌单一直没有新的？**
这是 ListenBrainz 还没为你生成，不是程序故障。常见原因见 [推荐联动详解 · 常见问题](docs/recommendation.md)。
